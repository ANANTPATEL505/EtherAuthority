# Blockchain Fundamentals & Ethereum Basics

A learning repository documenting my journey into blockchain technology and Ethereum development.

The goal is to understand how blockchain works internally, how Ethereum executes smart contracts, and how the Ethereum Virtual Machine (EVM) processes transactions.

## 📚 Topics Covered

### 1. Blockchain Fundamentals
- What is Blockchain?
- Distributed Ledger Technology (DLT)
- Decentralization
- Consensus Mechanisms
- Cryptographic Hashing
- Public and Private Keys

### 2. Ethereum Basics
- Ethereum Architecture
- Ethereum Accounts (EOA & Contract Accounts)
- Transactions and Blocks
- Ethereum Gas Mechanism
- Ethereum Virtual Machine (EVM)

### 3. EVM Internals
- How Solidity Converts into Bytecode
- How EVM Executes Smart Contracts
- Understanding Opcodes
- Stack, Memory, and Storage
- Gas Consumption During Execution
- Contract Execution Lifecycle

### 4. Solidity & Smart Contracts
- Solidity Fundamentals
- Data Types and Variables
- Functions and Modifiers
- Events and Errors
- Contract Deployment
- Smart Contract Interaction
